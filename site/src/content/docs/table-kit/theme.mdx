通过 `TableKit.configure({ theme })` 或 `editor.commands.tableKit.setTheme()` 可以切换 Table Kit 的主题模式。

<IframeDemo slug="theme-demo" sourceCode={getDemoSource('theme-demo')} client:load />

## 使用方式

### 静态配置

在扩展初始化时指定主题：

```ts
TableKit.configure({
  theme: 'dark', // 'light' | 'dark'
})
```

### 运行时切换

通过命令链动态切换：

```ts
editor.chain().setTableKitTheme('light').run()
editor.chain().setTableKitTheme('dark').run()
```

切换主题后所有 UI 组件（选区边框、操作手柄、上下文菜单、调色板等）会即时响应，无需重新创建编辑器。
