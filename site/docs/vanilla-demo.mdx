# 原生 JavaScript API

FSDX Editor 提供 `createEditor(container, options)` 原生 JavaScript API，无需 React 即可在任何 DOM 元素上创建编辑器。

```tsx file="./_vanilla-demo.tsx" preview
```

## 使用方式

```ts
import { createEditor } from '@fsdx/editor'

const editor = createEditor(container, {
  defaultContent: '<p>初始内容</p>',
  defaultTheme: 'light',
  placeholder: '请输入内容…',
  image: { upload: async (file) => ({ url: '...', name: file.name, size: file.size }) },
})

// 编辑器 API
editor.getHTML()      // 获取 HTML 内容
editor.getText()      // 获取纯文本
editor.setHTML(html)  // 设置 HTML 内容
editor.clear()        // 清空编辑器
editor.focus()        // 聚焦
editor.enable()       // 启用
editor.disable()      // 禁用
editor.setTheme('dark') // 切换主题
editor.isFocused()    // 是否聚焦
editor.isEmpty()      // 是否为空
editor.isDisabled()   // 是否禁用
editor.destroy()      // 销毁编辑器
```

## 事件系统

编辑器支持以下事件监听：

```ts
editor.on('change', () => console.log('内容变更'))
editor.on('focus', () => console.log('编辑器聚焦'))
editor.on('blur', () => console.log('编辑器失焦'))
editor.on('ready', () => console.log('编辑器就绪'))

// 移除监听
editor.off('change', handler)
```
