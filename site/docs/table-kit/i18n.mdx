# 国际化演示

通过 `TableKit.configure({ locale })` 控制右键菜单语言，支持中英文及自定义翻译覆盖。

```tsx file="./_i18n-demo.tsx" preview
```

## 使用方式

### 内置语言包

```ts
TableKit.configure({
  locale: 'zh-CN', // 简体中文
})
```

```ts
TableKit.configure({
  locale: 'en-US', // English
})
```

### 自定义翻译

可以覆盖部分翻译字段：

```ts
import type { TableKitTranslations } from '@fsdx/tiptap-table-kit'

const customTranslations: Partial<TableKitTranslations> = {
  deleteRow: '🔥 删除此行',
  deleteColumn: '🔥 删除此列',
  clearContent: '🧹 清除单元格',
  toggleHeaderRow: '📌 切换表头行',
}

TableKit.configure({
  translations: customTranslations,
})
```
