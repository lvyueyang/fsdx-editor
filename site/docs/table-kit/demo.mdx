## 功能说明

TableKit 提供以下能力：

- **插入表格**：支持自定义行列数的表格插入
- **行列操作**：插入、删除、上移、下移、左移、右移
- **单元格操作**：合并、拆分、清除内容
- **自适应列宽**：根据内容自动调整单元格宽度
- **表头切换**：切换标题行和标题列
- **主题切换**：浅色 / 深色模式实时切换
- **国际化**：中英文右键菜单切换
